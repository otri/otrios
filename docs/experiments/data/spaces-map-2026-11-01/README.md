# Spaces map design references

Illustrative browser concept figures for
[RFC 0028](../../../rfcs/0028-spaces-map-sharing-and-portable-data.md), captured
2026-11-01 at a 1024-pixel browser width in light appearance with reduced motion.
The figures record the design discussion, not a deployed interface or acceptance
test. Names, usage, activity and app content are sample fixtures. No live Frame,
authority state, account credentials or private display capture was accessed.

- `map-edit.png`: Edit mode, title dragging, corner resize affordances, six-app
  Experiments, an empty Space and a retained Notes dataset after removing its app.
- `app-settings.png`: editable Space-local name, stable bundle ID and the three
  app/data transfer actions.
- `space-settings.png`: combined name/background settings, usage and access.
- `app-download.png`: proposed ordinary-browser code download page and hosting entry.

The concept's transfer actions are simulations. RFC 0028 is authoritative for
the proposed behavior and explicitly identifies the remaining format and validation
work; these images are not proof that payload codecs or network operations exist.
