Prototype details

This prototype keeps edits in RAM. Publish is simulated. Native HTML controls stand in for OIB render/input; networking, signing, Wasmi and durable app state are not implemented.

Colors use local pairs here; full named-style resolution is not implemented.

Rebase here is a simplified model action, not a production merge workflow.
