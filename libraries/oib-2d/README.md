# OIB 2D library source

This data-only library supplies SettingsPanel, LabeledSlider and LabeledToggle.
`source.json` is Apache-2.0 authoring data. It contains no app values or rendering
handles. The publisher-scoped LibraryId names the existing OTriOS publisher;
a different publisher must choose its own logical identity.

Edit definition defaults, colors, geometry and composition here, pack with
`canvas-bundle library-pack`, sign with `library-sign`, and use `library-bind`
with `designer-bindings.json` to update OIB Designer's exact pin. Sign and install
the resulting app candidate through the existing unchanged-host workflow.
The contracts and full commands are in [L1](../../docs/OIB_LIBRARY_L1.md).

Binding maps retain definition/node/property identities across compatible
revisions. The source contract hashes are regenerated by `library-pack`; changes
that alter the exported contract require new admission. Application business
bindings, presets, grants and values belong to the app.

The Rust settings fixtures bootstrap applications and tests. Once a library is
installed, full-build revision tooling retains its exact pin and immutable body.
Library changes are explicit data publications and do not rebuild host binaries.
